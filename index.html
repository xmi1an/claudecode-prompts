1. Placeholders

Anything in [brackets] is yours to replace — [file], [feature], [error]. Copy the prompt, fill the brackets, send. Placeholders are highlighted in every card so you can spot them instantly.

2. The three rules that make any prompt work better

  1. Context: tell Claude what it can't infer — link files, paste errors, name constraints.
  2. Constraints: say what NOT to do ("don't refactor while you're here") — scope discipline is quality.
  3. Verification: demand proof — failing test first, test run after, screenshot, diff summary.

3. Beginner vs Pro

Beginner prompts work anywhere with no setup. Pro prompts assume things like plan mode, subagents, hooks, worktrees, or MCP — the deeper Claude Code toolkit.
